name=Vector Pivot Export
qgisMinimumVersion=3.22
description=Export any vector layer to Excel with a ready-made pivot table coloured by the layer symbology.
about=Writes an .xlsx workbook with a Pivot sheet (row / column / value fields of your choice, sum / average / min / max / count, optional area or length and % of total), the attribute table as an Excel table and a colour legend. Row and column labels are coloured like the layer's symbology (categorised, graduated, rule-based or single symbol). With Microsoft Excel installed on Windows the Pivot sheet is a real, refreshable pivot table; otherwise a static table with the same layout. Open it from the toolbar, Vector menu, a layer's right-click menu or the Processing Toolbox.
