name=Urban Design Setup
qgisMinimumVersion=3.22
description=Project setup, project arrange, layout automation, Export Land Use, vector pivot export and land use population in one plugin.
about=Urban design project tools in one plugin, under the Urban Design Setup menu and toolbar: Project Setup (layer tree, basemaps, live Indonesian datasets, OSM roads, styles), Project Arrange (sort loaded layers into the setup tree), Layout Automation (spatial bookmark x map themes to print layout pages and 300 dpi images), Export Land Use (land use plan to Excel pivots and PowerPoint tables / charts), Vector Pivot Export (any vector layer to an Excel pivot coloured by its symbology) and Land Use Population (resident / visitor / worker population per parcel from standards crosschecked against SNI 03-1733-2004 and Permen PU 26/2008, with an assumption preview window, a temporary population layer, an Excel workbook and a PowerPoint assumption table). Export Land Use and Vector Pivot Export are also in the Processing Toolbox under Urban Design Setup. Excel pivot tables need Microsoft Excel on Windows; the other outputs work on every platform. The plugin ships its own copies of python-pptx, XlsxWriter, typing_extensions and comtypes (in vendor/), PowerPoint / Excel templates used as report starting points (data/, population/) and QML layer styles (scripts/styles/). Uninstall the separate Export Land Use / Vector Pivot Export / Land Use Population plugins to avoid duplicate menus.
